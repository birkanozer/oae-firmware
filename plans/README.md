# plans/

One folder per feature: `plans/<feature-slug>/`. Each holds the feature's
**design doc** and **implementation plan**, plus `progress.md` (the subagent ledger) while the
feature is in flight. Produced by the `feature-workflow` skill (phases 1–2). Shipped features
move to `plans/archive/<slug>/`.

Naming: design docs `YYYY-MM-DD-<topic>-design.md`, plans `YYYY-MM-DD-<topic>-plan.md`.
