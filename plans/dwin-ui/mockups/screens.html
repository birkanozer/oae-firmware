OAE Robin E3 — Ender 3 V2 screen mockups (480×272)

Drawn with the same primitives the firmware uses (DWIN text with fixed font cells 8×16 / 10×20 / 12×24 / 16×32, filled and outlined rectangles). Night theme is the default. Degree and minute marks are drawn as small shapes because the screen fonts are ASCII-only. Knob: turn = move, click = select, hold = back.
