OAE Robin E3 — Ender 3 stock LCD (ENH12864Z-1, ST7920, 128×64) mockups v2, shown ×4

Each screen is a real 128×64 one-bit bitmap: layout, cell sizes and inversions are exact for the U8g2 fonts named (5×7, 6×10, 7×13 bold, 10×20). Glyph shapes are approximated by thresholding a system monospace font. Light pixels on the blue backlight. Knob: turn = move, click = select, hold (≥700 ms) = back / previous group. Header is 6×10 text with a dotted rule (no inverted bar); inversion is reserved for the selection bar, alerts and the STOP footer. Width limits enforced by the renderer: menu rows 19 cols, header state ≤12 cols beside an 8-col clock, other 6×10 lines 21 cols, 10×20 lines 12 cols.
